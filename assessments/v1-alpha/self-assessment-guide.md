# Self-Assessment Guide — Services Delivery Assessment

How to self-administer the services-delivery assessment without a facilitator.

---

## When to self-assess

- Initial baseline scan
- Quarterly delivery health check
- Pre-board reporting prep
- Pre-transformation readiness check

---

## Setup (30 minutes)

1. Pull the latest `instrument.yaml` from this repo
2. Identify one person per dimension:
   - **Predictability** — VP Engineering / Engineering Manager
   - **Flow** — Engineering Manager / Delivery Lead
   - **Quality** — QA Lead / Engineering Manager
   - **Outcomes** — Product Lead / Customer Success
   - **Team Health** — People Manager / Engineering Manager
3. Send instrument to each scorer
4. Agree a deadline (typically 1 week)

---

## Scoring

For each question:
1. Read the question
2. Read the evidence list
3. Score 0–3 based on evidence present
4. Cite evidence for scores of 2+

---

## Aggregation

For each dimension:
- Sum question scores (max = questions × 3)
- Compute `(sum / max) × 100`

For overall score:
- Multiply each dimension score by its weight
- Sum weighted scores

---

## Output

Fill in `gap-analysis-template.md` with scores, gaps, and quick wins.

---

## Follow-up

- **Within 30 days:** publish results
- **Within 90 days:** re-run assessment
- **Track trend** — lead time, CFR, NPS/CSAT

---

## Tips for accurate services delivery scoring

1. **Forecast accuracy requires commitment data.** Without tracking, score 0.
2. **Flow metrics must be live, not theoretical.** Score 0 if dashboards don't exist.
3. **Quality = escaped defects, not bug count.** Reframe question if needed.
4. **Outcomes need CX partnership.** Score 0 if CX isn't involved.

---

## When to escalate to a facilitated workshop

- Score < 50
- Significant organisational change
- Board-level reporting
- Conflict between scorers
